# PachiTracker の shared memory（共有メモリ）

このディレクトリは、チームで確認済みの再発防止ナレッジです。モデルを再学習させる仕組みや Codex 個人の記憶ではありません。

失敗や不具合は、まず incident（事象記録）として残します。lesson（教訓）を `active`（有効）にできるのは、根本原因、テスト済みの予防策、根拠、重複確認、独立した確認がそろう場合だけです。

作業開始時は `INDEX.md` のうち、対象に関係する `active` な lesson だけを読みます。完了後は、再利用価値のある失敗があれば `pachi_memory_curator` に整理を依頼できます。

認証情報、トークン、Webhook URL、Cookie、個人情報、生ログ、実データの行を絶対に記録しないでください。
